# Hello World — Product Requirements Document

## 1. Overview
A minimal, single-screen application that displays a title reading "Hello World".

## 2. Goal
Provide the simplest possible working screen to confirm the app builds, runs, and renders.

## 3. Scope
- **In scope:** One screen with a single title.
- **Out of scope:** Navigation, user input, settings, data persistence, or any additional screens.

## 4. Requirements

### Functional
- **FR-1:** The app shall display a single screen on launch.
- **FR-2:** The screen shall show a title with the text "Hello World".

### Non-Functional
- **NFR-1:** The title text must be clearly legible and centered.
- **NFR-2:** The screen should load instantly with no loading state.

## 5. Screen

| Element | Description |
|---------|-------------|
| Title   | Static text reading "Hello World" |

## 6. Success Criteria
- Launching the app shows one screen.
- The screen displays the title "Hello World".
